# Пешие маршруты

Маршруты внутри карты рассчитывает OpenRouteService, профиль `foot-walking`. Карта Google Maps остаётся подложкой. Запрос передаёт точки выбранного дня в порядке посещения, координаты GeoJSON идут как `[longitude, latitude]`. Для более 50 мест запрос разбивается на части с общей граничной точкой.

При смене дня незавершённый запрос отменяется. Результаты кэшируются в памяти Store до закрытия экрана. При ошибке остаются маркеры и кнопка повторной попытки. Для менее двух мест запрос не выполняется.

## Настройка

Добавьте `orsApiKey=YOUR_KEY` в пользовательский `~/.gradle/gradle.properties` и пересоберите приложение. Реальный ключ не хранится в репозитории и не логируется. Ключ Google Maps берётся из `mapsApiKey` в том же пользовательском файле и подставляется в manifest при сборке; Google Routes API и billing для прокладывания маршрута больше не нужны.

Бесплатный аккаунт OpenRouteService имеет квоты; актуальные значения доступны в личном кабинете. При исчерпании квоты экран покажет ошибку. BuildConfig не скрывает ключ в APK: для публичного приложения общий ключ лучше хранить на своём сервере.

Документация: [Directions](https://giscience.github.io/openrouteservice/api-reference/endpoints/directions/requests-and-return-types), [ограничения](https://openrouteservice.org/restrictions/).

## Остальные настройки API

В том же пользовательском `~/.gradle/gradle.properties` хранятся `apiKey` (Yandex AI), `folderId`, `promptId` и `mapsApiKey` (Google Maps). В проектном `gradle.properties` остаются только общие настройки сборки. На другой машине необходимо добавить эти свойства вручную; реальные значения не следует коммитить.
